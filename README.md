# Airbnb-NYC-Power-BI-Dashboard-Project
•	Developed an interactive Power BI dashboard evaluating Airbnb NYC data, visualizing trends by price, room type, and neighborhood.

•	Designed multiple visuals including maps, tree maps, stacked bars, donut charts, and highlight tables to uncover booking patterns.

•	Enhanced user experience with filters, tooltips and a clean layout, enabling intuitive exploration and data-driven insights for stakeholders.
